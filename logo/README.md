# Logo : le tampon (retenu)

Un sceau rond. « UNEMPLOYED STAFF » se lit en haut, « FREELANCES À MONTPELLIER » en bas, de gauche à droite. Au centre, le point de la charte : le freelance, entouré de l'équipe. Le mot-symbole Bricolage de la charte ne change pas et se place à côté du tampon.

## Règles

- **64 px et plus** : tampon complet.
- **Moins de 64 px** (favicon, petites pastilles) : version simplifiée `tampon-petite-taille`. Le texte devient un anneau plein.
- **Point coloré** : orange sur papier, jaune sur tapis, papier sur fond orange. Le texte reste en encre sur fond clair et en papier sur fond foncé.
- **À éviter** : déformer le tampon, faire tourner le texte autrement, ou changer la police (Bricolage Grotesque ExtraBold).

## Fichiers

| Fichier | Usage |
|---|---|
| `tampon`, `tampon-negatif`, `tampon-mono-encre` | Le sceau seul (fond clair, fond tapis, une couleur pour tampon encreur ou gravure) |
| `tampon-petite-taille`, `-negatif` | Version simplifiée pour les petites tailles |
| `logo-horizontal`, `-negatif` | Tampon et mot-symbole côte à côte (en-tête, signature mail) |
| `logo-vertical`, `-negatif` | Tampon au-dessus du mot-symbole (affiche, story, carte) |
| `icone-app`, `icone-petite-taille` | Icônes 1024 px sur le tapis |
| `planche-tampon` | Planche de présentation |

Chaque visuel est livré en **.svg**, **.eps**, **.ai** (compatible PDF, s'ouvre dans Illustrator) et **.png**. Le texte est vectorisé.

Les icônes du site (`img/apple-touch-icon.png`, `img/favicon.svg`, `img/favicon-32.png`) sont générées à partir de ce tampon.
